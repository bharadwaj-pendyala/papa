A readability linter for Markdown and plain text

Our documentation was written in order to basically explain the multifaceted functionality of the platform. We wrote these docs to explain what the platform does. Grade 16Grade 4

Papa grades each page of your docs the way the Hemingway editor does. It marks hard sentences, passive voice, adverbs, and wordy phrases, in your terminal and on every pull request.

pipx install papa-lint

Grade your own text

Paste a README or a paragraph. Papa runs in this tab, so your text never leaves the browser.

      Run the same check everywhere
      
    
      
      
      
        
      Terminal
      
        
      papa README.md docs/
papa docs/ --max-grade 10
papa post.md --report html -o report.html
      
        
      Exit code 1 when a file is harder than your max grade. Exit code 0 for findings alone.
      
      
      
      
      
        
      GitHub Action
      
        
      - uses: bharadwaj-pendyala/papa@v0
  with:
    paths: README.md docs/
    max-grade: 10
    comment: true
      
        
      Annotations on the diff, a job summary, and one PR comment that stays current.
      
      
      
      
      
        
      pre-commit
      
        
      - repo: https://github.com/bharadwaj-pendyala/papa
  rev: v0.2.0
  hooks:
    - id: papa
      
        
      Set max-grade in papa.toml to block hard commits.
      
      
      
      
      
        
      Agents
      
        
      papa draft.md --report json
      
        
      Offsets, lines, and a fix hint for each finding, so an agent can rewrite until the grade passes.
