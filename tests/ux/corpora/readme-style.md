## Status

Widget is **alpha** software. The supported surface is small:

- CLI command: `widget`
- Python package: `widget-lint`
- Reports: terminal and JSON

| Flag | Meaning |
|---|---|
| `--fast` | Skip the slow checks. |
| `--all` | Run every check. |

Issues are welcome. Good first issues are
[labeled](https://github.com/x/y/labels/good) for new people.
See https://example.com/guide for the full guide.
